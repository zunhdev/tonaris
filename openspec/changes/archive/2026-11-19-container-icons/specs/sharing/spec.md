# Spec Delta

## ADDED Requirements

### Requirement: Viewers see a share's icons
People a folder or list is shared with, signed in or as guests, SHALL see its folders' and lists' icons as the owner set them (FR-01.20, FR-07.11, TON-306).

#### Scenario: A guest sees a folder's icon
- **WHEN** the owner gives the folder 'Black' inside the shared folder 'Metal' a skull and a guest opens the link
- **THEN** 'Black' shows a skull
